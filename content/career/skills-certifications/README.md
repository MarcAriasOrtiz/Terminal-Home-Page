# Skills & Technologies

## Tools are just parts. The system is the point.

My work sits at the intersection of artificial intelligence, software engineering, data and infrastructure. Rather than specialising in a single tool, I combine these areas to design, build and run complete systems end to end.

Here is a breakdown of the six core areas I work across, the stack I reach for day to day, and how those pieces connect in practice.

---

### Artificial Intelligence & Machine Learning

Designing and adapting AI solutions, from classical machine learning models to task-specific language models running locally.

- Machine Learning
- Large Language Models (LLMs) & Small-Model Fine-Tuning
- Natural Language Processing (NLP)
- Retrieval-Augmented Generation (RAG)
- Graph-based Retrieval & Knowledge Systems
- Agentic AI Systems
- Model Development & Evaluation
- Applied Research and Experimentation

### Agentic Systems & Automation

Wiring workflows where AI agents, tools and backend services collaborate to execute real tasks instead of just chatting.

- Multi-Agent Systems
- Agent Orchestration

- Tool Integration
- AI-powered Automation
- Knowledge Retrieval Systems
- Workflow Design

### Data Engineering

Building the plumbing that collects, cleans and structures raw data so downstream models and teams can actually rely on it.

- ETL / Data Pipelines
- Data Integration
- Web Scraping & Data Extraction
- Database Management
- SQL & Data Modelling
- Workflow Orchestration

### Data Science & Analytics

Working with data to test hypotheses, build predictive models and turn noisy measurements into clear decisions.

- Statistical Analysis
- Exploratory Data Analysis
- Predictive Modelling
- Data Visualization
- Business Intelligence
- Analytical Reporting

### Software Engineering

Writing the backend services, APIs and glue code that connect models, databases and existing software without falling over.

- Backend Development
- API Design & Development
- Software Architecture
- System Integration
- Automation and Scripting
- Application Development

### Infrastructure & DevOps

Deploying, automating and monitoring the Linux servers, containers and networks that everything else runs on.

- Containerization
- Container Orchestration
- Infrastructure Automation
- Linux Systems
- Deployment & Environment Management
- Self-hosted Infrastructure

## How I Work

I approach engineering problems from a systems perspective. I like understanding how different components fit together, poking at technologies beyond their default settings, and combining them into something practical.

My strongest contribution is usually at the seams between disciplines: connecting AI with software, data with infrastructure, and an initial experiment with a system that actually runs.
