# AI

Projects where machine learning, language models and agents are the core of the
work.

- `graphrag-knowledge-agent.md` — an agent for searching and asking questions
  across a company's heterogeneous documentation.
- `fine-tuned-incident-labeling.md` — a fine-tuning pipeline that labels
  free-text incidents with 51 internal labels.
- `agentic-software-factory.md` — an orchestrator that assigns project-board
  tasks to specialised agents in containers.
- `pharma-faq-assistant.md` — a multilingual conversational assistant for a
  pharmaceutical company, built on Cognigy.
