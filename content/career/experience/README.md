# Experience

## From building single models to wiring the whole system.

My career has moved across data science, machine learning, natural language processing and software engineering, steadily shifting toward applied AI research and systems development.

Over time, the job stopped being about training a standalone model in a notebook and became about building the complete system around it: connecting models, data pipelines, backend services and Linux infrastructure so the result actually holds up in daily use.
