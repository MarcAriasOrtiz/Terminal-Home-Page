
# Roadmap

## Phase 0 — Project foundation
- Inspect the repository.
- Select and document the stack.
- Establish development and validation commands.
- Agree on architecture before implementation.

## Phase 1 — Homepage shell
- Build the visual terminal frame.
- Add the prompt and command input.
- Add a welcome message and initial filesystem.
- Add a first-visit boot intro: ASCII banner, short introduction and shortcuts, skippable, with `intro` to replay it.
- Make the layout responsive.

## Phase 2 — Identity
- Implement whoami.
- Write and refine the personal introduction.
- Add help and basic navigation commands.

## Phase 3 — Professional portfolio
- Add career and CV sections.
- Add a visual CV (`profile.md`) with a system map, print stylesheet and the written CV kept as the source.
- Add projects and technical stack.
- Add contact and LinkedIn links.

## Phase 4 — Personal lab
- Document the homelab and smart-home projects.
- Add selected technical diagrams or project write-ups.
- Keep private infrastructure details out of the public site.

## Phase 5 — Polish
- Accessibility and responsive checks.
- Performance and metadata.
- Error handling and command consistency.
- Final content review.

## Rule
Complete and validate one phase before expanding scope.
Do not implement future phases unless explicitly requested.
